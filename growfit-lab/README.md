# GrowFit Lab

این پوشه محیط آزمایش طراحی و توسعه GrowFit است.

## قوانین کار
- فایل‌های اصلی ریشه مخزن فقط مرجع خواندن هستند و در این محیط بازنویسی نمی‌شوند.
- هر قابلیت جدید ابتدا از نسخه اصلی بررسی و سپس به‌صورت مستقل در این پوشه پیاده‌سازی می‌شود.
- هر مرحله باید قابل مشاهده و آزمایش باشد.
- فقط پس از تأیید صاحب پروژه، درباره انتقال تغییرات به نسخه اصلی تصمیم‌گیری می‌شود.
- نام فایل‌ها و یادداشت هر مرحله باید روشن و قابل ردیابی باشد.

## ساختار پیشنهادی
- `index.html`: ورودی و فهرست نسخه‌های آزمایشی
- `modules/`: قابلیت‌های مستقل بازطراحی‌شده
- `assets/`: فایل‌های مشترک آزمایشگاه
- `notes/`: یادداشت تصمیم‌ها و وضعیت تأیید هر مرحله
